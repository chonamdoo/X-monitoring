Upload a PDF, drop signature fields, send, and get back a sealed document with a full audit trail, all self-hosted and legally compliant. The per-signature fee just stopped existing. 13K+ stars.

10. https://t.co/BFKKlPe4SN

Replaces: Intercom and Zendesk ($74+/agent/month).

A full customer-support suite, live chat, shared inbox, help center, and bots across email, WhatsApp, and socials. The per-agent pricing on the paid tools punishes you for every hire. Chatwoot runs on your server with no seat tax. 20K+ stars.

Claude Code 现在连商业广告片怎么做，都有人直接打包成 Skill 了。

项目叫 motion-video-kit。

它不是让 AI 随便生成几个镜头拼起来，而是给 Claude Code 一套完整的视频制作流程。

作者拆了 28 支专业 SaaS Launch Film，整理出：

动效规则、分镜方法、Three.js 3D 模式、音频规范和质量检查。

制作方式也比较实用：

AI 生成素材 + HTML/GSAP 动效 + Three.js 3D + 代码控制时间线。

比较特别的是它做了一套 Gauntlet 审片流程：

做视频的 Agent 不给自己打分。

每轮渲染后换一个新的 critic 看成片，列问题 → 修改 → 重新渲染 → 再验证。

一般跑 3～5 轮。

它还要求动画必须 deterministic：
跳到同一帧，就必须得到同样的画面。

所以最后交付的不只是 MP4，还包括：

分镜、源文件、素材生成记录、审片记录和修改结果。

我觉得这个方向挺有意思。

以前给 Claude Code 的 Skill，大多是在教它怎么写代码。

现在开始有人把 导演、动效设计和审片流程 也做成 Skill 了。

GitHub：https://t.co/XeOXsEIWix

如果视频制作流程也能被 Skill 化，以后真正拉开差距的会是模型，还是你手里积累的那套制作方法？
